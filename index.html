💡 명조 에코파고 v1.0 사용 가이드
  1. 화면 공유 시작 버튼을 누르고, 명조 게임 실행 창(또는 전체 화면)을 선택해 공유합니다.
  2. 좌측 스캔 상자를 마우스로 드래그하여 명조의 에코 부옵션 위치에 맞춥니다. (빨간색 상자에는 옵션명이, 노란색 상자에는 수치가 들어오도록 맞추세요.)
  3. 원하는 파밍 목표 프리셋과 유효 옵션 스탯을 체크하여 설정합니다.
  4. 에코를 강화할 때마다 이미 확정된 슬롯은 OCR을 건너뛰고 빈 슬롯만 즉시 고속 스캔(⚡ 1초 이내 반응)합니다. 우측에서 [강화 속행 / 즉시 손절] 판단 결과를 실시간으로 확인합니다.
  5. 다른 에코로 넘어가거나 새로 키울 때는 [새 에코 인식 (초기화)] 버튼을 눌러 슬롯을 비워줍니다. (오인식된 항목은 글씨를 클릭해 직접 수정 가능합니다.)
